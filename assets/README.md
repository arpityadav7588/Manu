# Manu Assets

Beep sounds are auto-generated by Manu on first run.

## Custom Wake Word (.ppn file)
To use a real "Hey Manu" wake word instead of Porcupine's demo keyword:
1. Go to https://console.picovoice.ai/
2. Sign up free → Wake Word → Create "Hey Manu"
3. Download the .ppn file → place it here as: assets/hey_manu.ppn
4. Set your API key in config.py: PORCUPINE_KEY = "your_key_here"
5. In engines/wake_word_engine.py, change:
   keywords=["porcupine"]
   to:
   keyword_paths=["assets/hey_manu.ppn"]
