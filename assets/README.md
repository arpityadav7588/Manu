# Manu Assets

## Beep Sounds
beep_on.wav  — Activation tone (880Hz). Auto-generated by Manu on first run.
beep_off.wav — Deactivation tone (440Hz). Auto-generated by Manu on first run.

These files are created automatically using Python's stdlib wave module.
No downloads or dependencies needed.

## Tray Icon
The system tray icon is generated programmatically using Pillow.
No image files needed.

## Custom Wake Word (Optional Upgrade)
For a dedicated hardware-accelerated wake word instead of Whisper-tiny:
1. Go to https://console.picovoice.ai/ — sign up free
2. Create a "Hey Manu" custom wake word
3. Download the .ppn file → save as: assets/hey_manu_windows.ppn
4. Install: pip install pvporcupine pvrecorder
5. In engines/wake_word_engine.py, replace the _load_tiny_model() and
   _listen_loop() methods with Porcupine-based implementation.
Result: ~0.1% CPU usage instead of ~2-3%, instant detection.
